Animal Shelter

The Animal Shelter project was completed as part of CS340 and gave me experience working with Python and MongoDB. The project used an AnimalShelter class to communicate with the database and perform database operations.

Project Information

Course: CS340 Advanced Programming Concepts

Category: Databases

Project: Animal Shelter

Technologies: Python, MongoDB, PyMongo

About the Project

The Animal Shelter project gave me experience working with a MongoDB database through Python. The project included an AnimalShelter class that provided a way for the Python application to communicate with the database.

Working on this project helped me understand how applications store, retrieve, and work with information in a database. It also gave me experience using database queries to find information that matched specific requirements.

My Enhancement

For my CS499 enhancement, I improved the search functionality of the AnimalShelter class. I added reusable search options that can be used to find information based on different pieces of animal data.

The enhanced search functionality includes options such as animal type, breed, age range, and combinations of filters. This made the database code more flexible because it could be used for different types of searches instead of only one basic query.

What I Learned

One of the biggest things I learned from this enhancement was the importance of making database code reusable. If an application needs to perform different searches, it is useful to have a flexible way to provide search information instead of creating completely separate code for every possible search.

I also learned more about how Python can communicate with MongoDB. The Python application provides a way to work with information stored in the database and return useful results.

Another thing I learned was that the way data is searched can have a big effect on how useful an application is. Adding different filtering options makes it easier to find specific information.

Challenges

One challenge I experienced while working with this project was making sure the Python application could connect to MongoDB correctly. I had to troubleshoot database connection and authentication issues during my coursework.

The enhancement also required me to understand the existing database code before adding new functionality. Instead of replacing everything, I kept the existing CRUD structure and built additional search functionality around it.
