Travlr Getaways

Travlr Getaways is a full-stack web application that I developed as part of CS465. The project gave me experience working with different parts of a web application and understanding how those parts communicate with each other.

Project Information

Course: CS465 Full Stack Development

Category: Software Design and Engineering

Project: Travlr Getaways

Technologies: Angular, Node.js, Express, MongoDB, JavaScript

About the Project

The Travlr Getaways project gave me experience working with a full-stack application. I worked with the front end, back end, routes, data, and database components of the application.

One of the things I learned from this project was how the different parts of a web application work together. The project helped me understand that software development involves more than just creating individual pieces of code. The different parts have to work together to provide a working application.

My Enhancement

For my CS499 enhancement, I went back to the Travlr Getaways project and looked at ways to improve the application. I focused on the administrative side of the application and improving the organization and functionality of the project.

The enhancement gave me the opportunity to work with an existing application instead of starting a completely new project. I had to understand how the original application worked before making changes to it.

What I Learned

One of the biggest things I learned from enhancing this project was that understanding existing code is an important part of software development. When working on a real project, developers will not always be starting from scratch. They may need to understand and improve software that someone else already created.

I also learned more about how front-end and back-end components connect and how changes to one part of an application can affect other parts.

Skills Demonstrated

Angular Node.js Express MongoDB JavaScript Full-Stack Development Software Design Troubleshooting

Course Outcomes

This artifact demonstrates my ability to design and evaluate a computing solution and use different tools and techniques to implement a software solution. It also demonstrates my ability to work with an existing application, identify areas that could be improved, and make changes to increase its usefulness.

The project also connects to the security mindset I developed during the Computer Science program because administrative functionality and user access are areas that need to be considered when developing software.
